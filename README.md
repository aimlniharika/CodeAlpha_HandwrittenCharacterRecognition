# Handwritten Character Recognition

## Project Overview
This project recognizes handwritten digits and letters using a Convolutional Neural Network (CNN) trained on the EMNIST dataset.

## Objectives
- Recognize handwritten digits from 0 to 9.
- Recognize uppercase letters from A to Z.
- Recognize lowercase letters from a to z.
- Display predictions through an interactive Gradio interface.

## Technologies Used
- Python
- TensorFlow and Keras
- CNN (Convolutional Neural Network)
- EMNIST Dataset
- NumPy
- Matplotlib
- Gradio

## Dataset Details
- Number of classes: 62
- Training images: 697,932
- Testing images: 116,323

## Model Performance
- Validation accuracy: 86.58%
- Training epochs: 5

## How to Run
1. Open the Jupyter notebook in Google Colab.
2. Run the notebook cells in order.
3. Load and preprocess the EMNIST dataset.
4. Train and evaluate the CNN model.
5. Launch the Gradio interface to test handwritten characters.
